\# LCTool-NC



Tool per la gestione delle Non Conformità, sviluppato in ASP.NET Core 9.



\## Requisiti



\- \[.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

\- \[Git](https://git-scm.com)

\- (Opzionale) Visual Studio 2022 con il carico di lavoro "ASP.NET e sviluppo web"



\## Installazione e avvio



1\. Clona il repository:



```bash

&#x20;  git clone https://github.com/Lux2030/LCTool-NC.git

&#x20;  cd LCTool-NC

```



2\. Ripristina le dipendenze e compila:



```bash

&#x20;  dotnet restore

&#x20;  dotnet build

```



3\. Avvia l'applicazione:



```bash

&#x20;  dotnet run --project LCTool\_NC

```



4\. Apri nel browser l'indirizzo mostrato nel terminale (es. `https://localhost:7xxx`).



\## Oppure con Visual Studio



Apri `LCTool\_NC.sln` e premi \*\*F5\*\*.
